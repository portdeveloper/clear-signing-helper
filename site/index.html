ERC-7730 coverage skill

An agent skill for writing ERC-7730 descriptors for the most-used contracts on Ethereum mainnet and opening them as draft PRs in the clear-signing registry, so wallets show those transactions as readable text instead of hex.

MIT GitHub and README · SKILL.md

Use it

Paste into Claude Code or another coding agent:

read https://raw.githubusercontent.com/portdeveloper/clear-signing-helper/main/SKILL.md and follow it to cover the next uncovered contracts of the ranking

The agent needs git, gh, uvx, Node, cargo and Foundry's cast.

If you are an AI agent

Follow SKILL.md (summary in llms.txt).

What is in it

  • Picking contracts from the Sourcify ranking, and which to skip: covered, custom encoding, unverified code, paused, bot-only, short-lived.
  • Rules for the screen: what the sentence must name, which arguments to pin so the screen holds for any value, label and intent lengths.
  • Tests from real transactions, with expected text taken from the registry's runners.
  • Checks: the registry's linter and both of its test runners, run before pushing.
  • The PR: one draft per protocol, labelled as not from the contract's owner.

Status

The rules come from the reviews of about 40 registry PRs written this way. One blind run on 2026-11-27: an agent given only the skill produced files that passed the linter and both runners in about 20 minutes. What it tripped on was added afterwards; the changed skill has not been run again.

This repository used to be a CLI, clear-signing-helper. It is on the tool branch and on npm, and is not being developed further for now.
